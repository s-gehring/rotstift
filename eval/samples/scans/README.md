# Echte Scans

Hier liegen selbst geschriebene, eingescannte oder fotografierte Seiten, je ein Bild und eine gleichnamige `.txt` mit dem Text, wie er auf der Seite steht. Eingebaute Fehler werden markiert wie in `../texts/`, also `{geschrieben|richtig|Art}`.

Nur eigene Handschrift, keine Arbeiten von Schülerinnen und Schülern.
